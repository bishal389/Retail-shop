## 📋 Project Overview

This project is a PHP and MySQL-based **Retail E-Commerce Website**, developed as part of a team-based university module. The platform supports both **User** and **Admin** sides, featuring product browsing, cart and checkout system, as well as a full admin dashboard for inventory and user management.
